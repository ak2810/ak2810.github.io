Privacy Policy

Effective date: September 29, 2026

Flag Battle Royale ("the application") is a desktop application operated by the owner of the YouTube channel @flags_battle_royale to run an automated live stream. This policy explains what information the application accesses and how it is handled.

Information accessed through Google / YouTube APIs

When the channel owner authorizes the application with their Google account, it uses the YouTube Data API (scope https://www.googleapis.com/auth/youtube) only to:

  • read the authorized channel's ID and title to confirm the correct channel is used;
  • create, bind, start, monitor and end live broadcasts and live streams on that channel;
  • set the title, description, category and tags of those broadcasts.

The application does not read, collect or store data about viewers or any other YouTube users, and it does not access comments, live chat, subscribers, analytics or any other account data.

Storage and security

The OAuth refresh token is stored only on the owner's own computer, encrypted with Windows Data Protection (DPAPI). Access tokens are kept in memory only. No data is sent to any server other than Google's official APIs over HTTPS. Credentials are never logged.

Sharing

No information obtained through Google APIs is sold, shared with or transferred to third parties, or used for advertising.

Flag Battle Royale's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions or with the application's youtube-logout command, which also deletes the locally stored token.

Viewers

Viewers who watch the stream on YouTube interact only with YouTube; their data is governed by the Google Privacy Policy. This application collects no viewer information.
