Flag Battle Royale

An autonomous, 24/7 live flag battle. Hundreds of country flags bounce inside a circular arena, a moving gap opens in the ring, and the last flag standing qualifies for the Grand Final.

Watch live: youtube.com/@flags_battle_royale

About the application

Flag Battle Royale is a desktop application run by the channel owner on their own computer. It renders the game and uses the YouTube Data API to create, start and end live broadcasts on the owner's own YouTube channel. It does not offer sign-in to the public and does not access any other user's data.
